# Dataset policy

Place only public, licensed, anonymized datasets here. Recommended research sources include IEEE-CIS Fraud Detection, public credit-card fraud datasets, public phishing URL corpora, and public SMS spam/scam datasets. Record the source URL, license, version, fields, preprocessing, and known limitations. Historical dataset rows must never be shown as live banking activity. Do not add passwords, PINs, CVVs, OTPs, private keys, login credentials, or real personal information.
