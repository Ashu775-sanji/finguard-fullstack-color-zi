## Scope and limitations

The shield is lightweight CSS/Framer Motion, not a WebGL model. Demo summaries are explicitly sample analysis. Recorded-data fallback is not represented as an LLM response. Scores are model estimates, not bank security ratings. FinGuard has no live bank connection and cannot block payments or guarantee fraud detection/recovery.
